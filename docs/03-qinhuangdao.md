# 秦皇岛专题

## 区域产业背景

2026年2月的报道援引秦皇岛市工信局数据：2025年装备制造产业营业收入1089亿元，年末规模以上装备制造企业186家。引用层级是“媒体转述政府数据”，统计范围为装备制造，不能写成自动化行业规模或岗位数。[S21 · 王东／河北新闻网，新浪转载](https://finance.sina.com.cn/jjxw/2026-02-02/doc-inhkkzkc7473740.shtml)

区域调研的价值在于找到实际生产场景：汽车零部件的搬运与加工、玻璃生产的检测与过程控制、专用装备的机加与物流，以及能源装备中的测试与控制。

## 代表案例如何展开

中信集团2021年通稿确认戴卡铝车轮工厂入选灯塔工厂。它可作为数字化精益管理的历史案例；其他厂区的认定、当前设备数量和产能需要分别核对。[S10 · 中信集团](https://www.group.citic/html/2021/media_news_0929/2438.html)

省工信厅刊载的2025年秦皇岛经开区报道还提供晟成自动化建设项目线索。本版仅依据可检索文本作跟踪入口，不把当时的竣工预期写成已实现。[S13 · 河北省工业和信息化厅](https://gxt.hebei.gov.cn/hbgyhxxht/xwzx32/dfgz28/2025070909020646725/index.html)

原始文件中耀华、科力、秦皇岛烟机、爱迪特、礼鼎等企业可继续作为调研对象。但“具体年份智能工厂认定”“产线数量”“检测精度”等应对应明确文件和设备型号；本版没有补齐的条目保留在待核实计划中。

## 人才培养与政策线索

燕山大学电气工程学院的控制学科介绍涉及网络化控制、复杂机电系统集成、新能源控制等研究方向，可以用来理解本地学科与制造场景的联系。它不代表当年实验室接收名额。[S14 · 燕山大学电气工程学院](https://iee.ysu.edu.cn/info/1545/14350.htm)

河北省2026年度智能工厂培育通知说明基础级建设、先进级培育与更高层级推荐的工作安排。对调研而言，这可以提示不同企业的改造阶段；通知中的具体申报日期不能当成长期有效的报名入口。[S11 · 河北省工业和信息化厅](https://gxt.hebei.gov.cn/hbgyhxxht/xwzx32/tzgg83/2026022508574592407/index.html)

## 下一次走访可以问什么

1. 自动化改造首先要解决哪一道工序的质量、节拍或劳动强度问题？
2. 控制程序、机械机构、检测设备与生产管理系统由哪些团队负责？
3. 项目怎样完成异常测试和验收？学生能接触哪一部分？
4. 新人先承担什么任务，是否有带教和文档规范？
5. 哪些信息可以公开引用，哪些只用于内部学习？

这些是建议访谈问题，本项目尚未开展企业访谈。使用[企业调研模板](../templates/company-research.md)记录真实回答。
