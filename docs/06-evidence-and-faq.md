# 数据口径与常见问题

[返回首页](../README.md) · 更新：2026-09-23

## 为什么不发布一张企业薪资排行榜

原始资料含有全国头部企业校招区间和秦皇岛不同经验岗位区间，但没有一致的职位样本、日期及收入定义。将这些数字排在一起容易把地区、学历、经验、奖金和出差补贴混为一谈。论文保留原始材料的参考范围与说明；在线指南不把它们作为当期市场统计。

后续若做薪资分析，每条至少需要企业、岗位编号、地点、发布时间、经验、学历、月薪区间、发薪月数、奖金、补贴与原始链接。未公开项填“未披露”，不要补成0。样本充分后再讨论分布，并说明样本来自哪些平台和筛选条件。

## A级来源是否意味着结论全部真实

A仅表示已取得并核对相关页面原文。企业官网仍属于企业自述，政府公示仍有拟认定与正式认定之分，媒体仍可能转述其他机构的数据。验证“页面说了什么”与独立验证“实际效果如何”是不同任务。

## 为什么保留B级条目

部分官方网页有动态渲染、访问防护或格式限制，但其官方检索文本仍能确认资源或业务入口。B级只支持有限描述，不用于金额、性能排名、确定性招聘门槛或复杂技术结论。正文中明确标注，后续可补齐原文后升级。

## 哪些原始说法没有直接沿用

| 原始材料中的说法类型 | 本版处理 |
| --- | --- |
| 本科只能调试，研发统一要求硕士 | 改为岗位方向差异，学历条件需要当期JD |
| 测试岗位门槛最低 | 不保留；工作难度取决于对象与验证责任 |
| 大多数岗位或某品牌占比最高 | 没有抽样或统计则不保留占比结论 |
| 所有公司统一英语门槛或固定投递次数 | 转为待核对项，不作为求职规则 |
| 机器人定位精度直接代表所有设备 | 必须注明型号、指标定义和测试条件 |
| 预计投资或园区入驻数量等于岗位数量 | 不作这种换算 |
| 拟支持公示等于项目获批投产 | 保留公示原始阶段 |

## 是否做过实地访谈或实验

没有。本版采用资料分析与案例比较，项目、访谈提纲和学习安排均为建议。后续新增访谈和实测，应分别注明日期、方法、公开范围与原始记录，不能将模板当作已经完成的结果。

## 原始三份文件在哪里

它们作为初始整理线索列入来源记录，没有随公开包复制。下载版为整合后的报告；若补充第三方文档，优先保留原发布链接及摘要。

## 怎样提交纠错

指出具体段落，提供能支持修正的原始页面，写清数据年份、概念和状态。发现链接失效可以提交问题，但“打不开”不自动证明历史事实错误。请查看[补充指南](../CONTRIBUTING.md)。
