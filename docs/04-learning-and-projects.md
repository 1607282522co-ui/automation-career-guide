# 学习与实践

[返回首页](../README.md) · 更新：2026-09-23

本章是学习设计建议。所列项目未声称已搭建、通过实测或获得企业认可；应依据实验室设备和课程要求调整。

## 先建立共同基础

| 基础 | 建议验证方式 |
| --- | --- |
| 反馈与控制 | 能解释设定值、测量值、误差与执行动作，比较响应变化 |
| 电气与传感器 | 能从图纸追踪输入输出，说明量程、单位和异常含义 |
| 编程与状态逻辑 | 能把工艺写成状态图，并解释每个转移条件 |
| 测试与记录 | 能重复操作、保存原始结果、区分假设与观察 |
| 工程表达 | 别人可根据说明运行项目并理解自己的贡献 |

控制理论入口可使用[CTMS](../sources.md#s18)，PLC路径可查看[西门子SCE](../sources.md#s05)，嵌入式路径可查看[RoboMaster例程](../sources.md#s16)和[FreeRTOS官方教程](../sources.md#s17)。其中部分网站访问或下载有条件，详见[资源导航](05-resources.md)。

## 项目一 具备异常恢复的小型分拣线

**适合方向：** PLC、电气集成、设备运维。可先用仿真完成控制逻辑，实物阶段在实验室指导下进行。

任务包括物料检测、输送、计数和分类；手动、自动、停止与复位状态必须定义清楚。传感器异常、工位超时、重复启动和中途停止后，程序应给出可解释的状态。

交付物：需求说明、I/O表、状态图、PLC程序、HMI画面、正常和异常测试记录、操作说明。完成判据：每一项需求对应至少一项测试；执行结果与预期不一致时保留缺陷记录，并复测修正。

## 项目二 电机或定位平台的控制实验

**适合方向：** 嵌入式、运动控制、装备研发。

先确定对象、采样方式与测量单位，再比较不同参数下的响应。记录负载、目标值、采样周期和控制参数，观察误差和振动；对模型与实测不一致之处作解释。不要把一次漂亮曲线当成全部性能。

交付物：硬件连接说明、程序、参数表、原始数据与曲线、误差分析。完成判据：在预先说明的工况下可重复运行；报告明确哪些来自仿真、哪些来自实测，指标在实验前给出定义。

## 项目三 设备状态采集与批次追溯

**适合方向：** 工业数据、MES接口、上位机开发。

从模拟设备读取运行状态、计数和故障事件，按批次保存并展示。设计掉线与重新连接场景，保留事件时间、设备编号与数据质量说明。OPC UA的信息建模和访问机制可作为接口学习资料；采用哪一种协议由设备条件决定。[S15 · OPC Foundation](https://opcfoundation.org/about/opc-technologies/opc-ua/)

交付物：数据字典、接口定义、采集程序、示例数据库与查询、异常日志。完成判据：相同数据定义在采集、存储和显示中保持一致；重复或缺失事件可被解释。所有演示数据标注为模拟，不充当工厂生产数据。

## 项目四 机器人通信与任务管理演示

**适合方向：** 机器人软件、系统测试。可以使用ROS 2仿真环境，无须购买整套机器人。

建立状态发布、任务请求与结果反馈，记录成功、超时和取消过程。使用指定版本的文档，先理解接口语义，再加入更复杂的算法。本版列出Jazzy接口文档作为入口，不把它标为最新发行版。[S19 · ROS 2官方文档](https://docs.ros.org/en/jazzy/How-To-Guides/Topics-Services-Actions.html)

交付物：节点与接口说明、启动步骤、运行日志、测试用例、演示。完成判据：他人按说明可复现；错误输入和超时有明确结果；没有把仿真演示写成真实机器人验证。

## 建议的十二周安排

| 阶段 | 时间建议 | 应形成的成果 |
| --- | --- | --- |
| 需求与基础 | 第1—2周 | 方向、需求、学习资源、设备条件 |
| 最小功能 | 第3—5周 | 可运行的单模块与测试记录 |
| 系统与异常 | 第6—9周 | 接口联调、异常与恢复验证 |
| 复现与表达 | 第10—12周 | 文档、数据、演示、项目复盘 |

时间表只是组织学习的建议，不承诺达到就业要求。根据课程基础可延长任一阶段。使用[项目复盘模板](../templates/project-review.md)记录进展。
