## 本版有什么

三个原始调研文件构成初始研究线索；网络来源登记表收录21条条目，包括行业组织、企业、政府部门、院校及官方技术教程。新增了秦皇岛机器人改造项目线索、控制与通信学习入口，以及4个带交付标准的实践项目建议。

本项目是一份资料整理与案例分析，不是企业排名，也没有实施访谈、招聘抽样或薪资统计。企业案例说明业务场景，岗位能力表是研究归纳，不代表企业当前招聘条件。学习项目是建议任务，没有声称已完成实测。

## 怎样判断信息可靠性

- **A 原文已核对**：已取得相关页面正文；仍保留企业自述、媒体转述等来源属性。
- **B 官方索引已核对**：官方网页的检索文本可核对，直接访问受限或未返回正文。仅用作简要线索或资源入口。
- **C 原始材料待核实**：初始文件中的线索，尚未取得逐条原始证据；不当作当期招聘事实。

[来源与核验记录](sources.md)逐条列出链接、时间、支持内容和使用边界；[机器可读来源表](data/sources.json)便于后续维护。
