## 有来源，也有使用边界

> 本项目属于**资料整理与案例分析**。未实施访谈、招聘抽样或薪资统计；企业案例不等于当前招聘条件，实践项目属于建议任务。

| 标记 | 核验状态 | 使用方式 |
| :---: | --- | --- |
| **A** | 原文已核对 | 已取得相关页面正文，保留企业自述、媒体转述等来源属性。 |
| **B** | 官方索引已核对 | 检索文本可核对，正文访问受限或未返回；用于简要线索与资源入口。 |
| **C** | 原始材料待核实 | 初始文件中的待核实线索，不作为当期招聘事实。 |
